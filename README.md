# Пісня про тебе | Ksena Rika

Telegram-бот для замовлення персональних пісень.

## Можливості

- анкета замовлення українською;
- пакети «Експрес» і «Преміум»;
- фото, голосові та інші вкладення;
- оплата Telegram Stars;
- передавання оплаченого замовлення адміністратору;
- доставка готового MP3 клієнту;
- команда `/myid` для визначення Telegram ID адміністратора.

## Змінні середовища

- `BOT_TOKEN` — секретний токен від BotFather;
- `ADMIN_CHAT_ID` — Telegram ID адміністратора;
- `WEBHOOK_SECRET` — створюється автоматично;
- `EXPRESS_STARS` і `PREMIUM_STARS` — ціни у Telegram Stars.

Секретні значення не можна записувати у файли GitHub.
